naeilo는 어떤 사이트인가요

보유 주식의 종목과 수량만 넣으면 지금 내 자산이 얼마인지, 목표 금액까지 얼마나 왔는지, 앞으로 3년(목표일까지) 어떻게 될지를 보여 주는 무료 자산 관찰·전략 도구입니다.

  • 시세는 자동으로 모입니다. 원화 평가액은 매매기준율(서울외국환중개 고시 환율)로 계산합니다.
  • 미래는 하나의 숫자가 아니라 수천 개 경로로 계산한 범위와 확률로 보여 줍니다.
  • 입력값은 이 브라우저에만 저장됩니다. 회원 가입이 없고 서버는 보유 내역을 모릅니다.
시작하기자산 추이분석·전략인사이트설정알아 두면 좋은 기능

시작하기 (1분)

  1. 설정 탭 맨 위 보유 종목에 종목(예: TSLA, 005930.KS)과 수량을 넣고 종목 추가. 매수 단가는 선택이며, 넣으면 손익이 나옵니다.
  2. 자산 추이 탭에서 목표 수정을 열어 목표 금액·목표일·월 적립을 고릅니다. 기본값(10억, 3년)을 그대로 써도 됩니다.
  3. 끝. 나머지는 모두 기본값으로 계산됩니다. 다른 선택지는 각 화면의 옵션에 접혀 있습니다.

자산 추이

내 자산의 현재와 흐름을 보는 첫 화면입니다.

  • 목표 진행: 목표 대비 진행률과, 목표까지 가는 기준 경로보다 몇 원 앞서거나 뒤처졌는지. 공유 이미지로 금액을 숨긴 진행 그래프를 저장·공유할 수 있습니다.
  • 평가액 추이: 1개월~3년, 그리고 과거3년+미래(목표일까지 전망). 원화/달러 전환. 보기 옵션에서 일·주·월 간격, 합계·누적·종목별, 미래 기준(내 관점·현재 정세·과거 추세)을 바꿉니다.
  • 기간 수익률: 기간별 원화 수익률. 중간에 종목을 사고판 효과는 빼고 계산합니다.
  • 자산 추이 분석: 위 숫자를 글로 풀어 쓴 해설.

분석·전략

미래 전망과 전략을 6개 세부 탭으로 나눠 봅니다. 맨 위 계산 옵션에서 시나리오(내 관점·기준·보수·과거 반복·스무딩 추종·추세 추종)와 경로 수를 바꿀 수 있습니다.

3년 전망
세 개의 렌즈(현재 정세 / 과거 추세 / 내 관점)로 목표 달성 확률을 비교합니다. 추세를 얼마나 믿나요 슬라이더로 내 관점을 정하고, 만약에에서 월 적립·일부 매도를 가정해 볼 수 있습니다(저장 안 됨). 아래 그래프는 전체 또는 종목별, 외부 요인 반영 여부별로 볼 수 있고, 연도별 목표 도달 확률도 나옵니다.
외부 요인
금리·환율·원자재·정치(거시), 실적·신제품·KPI(기업), 기관·외국인 매매(수급) 같은 사건을 타일로 보여 줍니다. 타일을 누르면 켜고 끄며, 전망에 얼마나 영향을 주는지와 내 자산의 민감도를 보여 줍니다. 사건을 직접 추가·편집할 수도 있습니다.
종목 전략
종목별 가격 그래프, 포트폴리오 진단, 종목마다 비중·추세·전망을 바탕으로 한 전략 카드(보유 / 추가 매수 보류 / 비중 축소 검토 등)와 그 이유.
비중 조정
지금 비중과 여러 조정안을 비교하고, 조정안별 미래 평가액(중앙값·나쁜 경우·좋은 경우)과 실행 계획(몇 주를 사고팔지)을 보여 줍니다.
배당·세금
앞으로 1~3년 예상 배당·이자(세후, 원화)와 해외주식 양도소득세(250만원 공제, 22%)를 연도별로 계산해 세금을 줄이는 매도 시점을 잡도록 돕습니다.
환율 영향
원/달러 환율의 과거와 전망, 매매기준율, 환율이 오르내릴 때 내 평가액이 얼마나 바뀌는지.

인사이트

  • 미래 가치 인사이트: 보유 종목과 관련 업계의 기사를 자동으로 모아 한국어로 요약합니다. 읽은 기사는 표시되고, 새로 고치거나 더 보기로 바꿔 볼 수 있습니다.
  • 미래 설계 naeilo: 투자와 미래 설계에 관한 글 모음. 공감과 댓글을 남길 수 있습니다.

설정

  • 보유 종목: 종목·수량·매수 단가를 넣고 고칩니다.
  • 시세 수집: 최신 시세를 바로 받습니다. 옵션에서 현재가만 받기, 자동 갱신(1~60분).
  • 거래 기록: 수량을 바꾼 날이 자동으로 기록됩니다(가격은 그날 종가). 날짜를 고치거나 지울 수 있습니다.
  • 입력값 저장·불러오기: 다른 기기로 옮기기(QR·링크), JSON 내보내기·불러오기, 그리고 기기 자동 동기화.
  • 알림: 하루 5% 넘게 빠지거나 실적 발표 하루 전에 알림(수량·금액은 보내지 않음).
  • 표시 옵션·모형 설정: 화면 표시와 계산 기본값. 손대지 않아도 됩니다.

알아 두면 좋은 기능

상단 "자산 ○억"을 누르면 → 종목 추가·수량 수정
어느 화면에서든 머리글의 자산 금액을 누르면 설정의 보유 종목 표가 열립니다.
상단 알약(진행률 막대)을 누르면 → 시세 수집
목표 진행률 막대를 누르면 바로 최신 시세를 받아 다시 계산합니다.
기기 자동 동기화 (휴대폰 ↔ PC)
설정 → 입력값 저장·불러오기 → 기기 자동 동기화에서 동기화 비밀번호(10자 이상)를 넣고 켜기. 쓰는 기기마다 같은 비밀번호를 넣으면 입력값이 자동으로 맞춰집니다. 기기에서 암호화한 값만 서버에 두므로 서버는 보유 내역을 볼 수 없고, 비밀번호를 잊으면 복구할 수 없습니다.
화면별 해설 켜고 끄기
설정 → 표시 옵션 → "화면별 해설 보이기". 끄면 각 화면 아래의 해설 카드가 사라져 화면이 짧아집니다.
현재가 직접 입력
설정 → 표시 옵션 → 보유 종목 표에 "현재가 직접 입력" 칸 보이기. 시세가 늦거나 없는 종목(장외·주간거래 등)의 가격을 손으로 넣을 수 있습니다.
거래 기록 보기
설정 → 거래 기록. 수량을 바꿀 때마다 날짜와 그날 종가가 남아, 언제 사고팔았는지 돌아볼 수 있습니다.
백업
입력값은 이 브라우저에만 저장됩니다. 동기화를 쓰지 않는다면 가끔 입력값 내보내기로 백업해 두세요. 오래 백업하지 않으면 첫 화면에 알림이 뜹니다.
홈 화면에 추가
휴대폰 브라우저의 "홈 화면에 추가"로 앱처럼 쓸 수 있고, 오프라인에서도 마지막으로 본 화면이 열립니다.
로고를 누르면
어디서든 자산 추이 첫 화면 맨 위로 돌아갑니다.

전망은 과거 데이터와 가정으로 계산한 참고값이며 투자 권유가 아닙니다.
