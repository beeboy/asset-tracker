개인정보 처리방침

naeilo 웹(naeilo.com)과 아이폰 앱 'naeilo 위젯'(이하 naeilo)에 적용됩니다. 시행일: 2026년 10월 16일.

  • naeilo 는 회원 가입이 없고, 이름·전화번호·위치·연락처·광고 식별자를 모으지 않습니다. 이메일은 아래 '출시 알림 신청'에 직접 넣은 경우에만 받습니다.
  • 광고, 분석 도구, 추적을 쓰지 않습니다.

기기에 저장되는 것

  • 웹: 보유 종목·수량·매수 단가·목표 같은 입력값은 이 브라우저(localStorage)에만 저장됩니다.
  • 아이폰 앱: 동기화 비밀번호는 저장하지 않습니다. 비밀번호에서 만든 저장 위치와 암호 키만 아이폰 키체인에 두고, 위젯에 보여 줄 요약 값은 앱 안에만 둡니다. 로그아웃하면 모두 지워집니다.
  • 아이폰 앱: 게임 '판 깨기' 점수는 이 폰 안의 '내 기록 순위'에만 저장하고 서버로 보내지 않습니다.

내 오픈 API 키로 시세 받기 (선택, 아이폰 앱)

  • 설정 > 오픈 API 에 직접 발급받은 토스증권 Open API 키(client_id·client_secret)를 넣으면, naeilo 중계 서버(toss.naeilo.com)를 거쳐 토스증권에서 국내·미국 종목의 지금 가격, 지난 종가, 원/달러 환율을 받습니다.
  • 키와 토스증권이 발급한 접속 토큰은 이 아이폰 키체인에만(이 기기 전용) 저장하고, 같은 앱의 위젯이 함께 읽습니다. naeilo 서버에는 저장하지 않습니다.
  • 중계 서버로 보내는 것은 키(토큰을 받을 때), 토큰, 시세를 받을 종목 코드뿐입니다. 보유 수량·매수 단가 같은 입력값은 보내지 않습니다.
  • 중계 서버는 받은 요청을 토스증권에 그대로 넘기고 응답을 돌려줄 뿐, 키·토큰·요청 내용을 저장하거나 기록(로그)에 남기지 않습니다. 토스증권은 등록한 IP 에서 온 호출만 받기 때문에, 고정 IP 인 이 중계를 토스증권 허용 IP 에 등록해야 합니다.
  • 중계는 시세·종가·환율만 넘기며, 주문·계좌·자산 정보는 부르지 않습니다. 과도한 호출을 막으려고 접속 IP 별 1분 호출 횟수만 서버 메모리에 잠시 셉니다.
  • '키 지우기'를 누르면 키·토큰·받은 시세가 이 폰에서 지워지고 기본 시세로 돌아갑니다. 발급한 키 자체는 토스증권에서 따로 지울 수 있습니다. 웹에는 이 기능이 없습니다.

출시 알림 신청 (선택, 웹)

  • naeilo.com 입구에서 '출시 알림 받기'에 넣은 이메일 주소와 신청 날짜만 중계 서버(Cloudflare)에 저장합니다. 보유 종목·수량 등 다른 입력값은 함께 보내지 않습니다.
  • 이 이메일은 앱 출시를 알리는 메일 한 번에만 쓰고, 보낸 뒤 지웁니다. 다른 곳에 주거나 광고에 쓰지 않습니다.
  • 그 전에 지우고 싶으면 입구의 '신청 취소'에 같은 이메일을 넣거나 아래 문의로 알려 주세요.

구독 (선택, 아이폰 앱)

  • 구독(7일 무료 뒤 월·연 자동 갱신)은 Apple 인앱 구매로 처리되며, 결제 정보는 앱이나 naeilo 가 받지 않습니다.
  • 7일 무료가 시작된 날은 아이폰 키체인에만 둡니다.
  • 구독으로 열리는 원고를 받을 때, 구독을 확인하려고 Apple 이 서명한 거래 정보(상품·거래 번호·날짜, 이름·연락처 없음)를 중계 서버(Cloudflare)로 보냅니다.

외부로 나가는 요청

  • 시세·환율·뉴스는 naeilo.com 과 중계 서버에서 받습니다. 이때 보유 내역은 보내지 않습니다(새 종목 시세를 받을 때는 종목 코드만 씁니다).
