# 화면·기능 남은 일

- 적힌 날 기준이다. 끝났는지 확인 안 함.
- 끝나면 줄을 지운다.

- 기기 옮기기 새 문구 영어를 아이폰 xcstrings에도 옮긴다.
- 중계 IP: 아이폰은 아직 받기만 한다.
- 안드로이드 숫자 칸 키보드가 바로 사라진다(flip4, 원인 안 봄).
- 안드로이드 위젯 contentDescription 영어.
- 흐름 탭 확인 못 함: 토스 캔들 이름·값, 알파카 sip 일봉, 실데이터 패턴 양. 안드로이드 핀치·키 화면·실데이터.
- 내 몫 실적: 국내 DART 없음, 해외 20-F 줄표, `SEC_UA` 시크릿 넣기. 시뮬레이터 손 검사·판16 좌표 대조·안드로이드 화면 손 검사 아직. 안드로이드 실기기 기다리는 중 강 확인.
- 종목 탭: 띠 이름 미정(후보 '등락 띠'). 가운데 그래프 카드 둘지 미정. 종목 세부 시안·계산기(v34·v36, 확인 전). 내 몫 화면 v39·v40 고칠 것.
- 안드로이드: 출시판 경고 8, 밀린 이름표 Market.swift·SettingsDetail.swift, 시뮬레이터와 나란히 비교 아직.
- 분석 탭 새 문구 약 35개 영어 없음. xcstrings에 넣고 `gen_en.py`.
- 삼성 setRequestedFrameRate 로그로 main CPU 약 11%. paths_mc.plist 52.8MB 그대로.
- 설정 화면 정리(10-24)는 커밋 전 빌드 확인 대기였다.
