## 1. 서비스 목적
- 이름: **naeilo** (Beyora → BEEBOY → naeilo, 2026-10-05 확정). 도메인 naeilo.com. 슬로건 "See Tomorrow, Today."
- 사용자가 보유 종목의 **수량만** 넣으면 원화 평가액, 목표 또는 본전까지의 길, 확률 전망(몬테카를로)을 보여 주는 **자산 관찰 도구**입니다.
- 종목별 매매 조언이 아니라 거시 관찰 도구입니다. 화면에는 비율과 확률만 보여 주고 "종목 + 금액 + 시점"은 쓰지 않습니다 (유사투자자문 위험).
- 시작은 개발자 본인용(3년 안에 10억 목표)이었고, 공개 서비스로 넓히는 중입니다.
- 웹과 앱의 역할: 웹은 관찰·분석 도구, 앱은 습관·정서(인물·쉼터·미션). 미션과 계획 고르기는 앱 전용입니다.

## 2. 타깃 사용자
- 2026-10-09 결정(타겟층 분석): 1차는 **미국 개별주에 집중했다가 손실 중인 개인**(레버리지 보유자 제외), 2차는 적립식으로 막 시작한 사람. 시작 전인 사람은 입구로만 둡니다.
- 첫 질문 하나로 "회복" 루트와 "목표" 루트(앱은 "시작 전" 포함 3루트)를 나눕니다. 고급 기능은 "자세히" 안에 접습니다.
- 2026-10-12 기획팀 합의 #1: 첫 타깃은 손실 중인 사람(본전을 기다리는 사람), 장투족도 같은 결. 상태는 "방향"이며 확정 표시는 없습니다.
- 2026-10-12 결정: 주 대상은 미국 사용자와 미국 주식을 가진 한국 투자자.
- 2026-10-14 사용자 답: 출시 대상 국가는 **미국·한국**. 출시 시점은 **보류**(지금은 내부 테스트 기간).

## 3. 요금 방향
- 기본은 수량만 입력, 부가 항목(현금, 실제 기록 등)은 나중에 무료/프리미엄으로 나눔. 웹 현금 기능은 지금 모두에게 켜져 있음 (`web/app.js` 설정 섹션 `premium()`이 항상 true).
- 모의 바구니: 무료 1개, 프리미엄 여러 개 (합의 #4).
- 앱 후원: 인앱 결제 단계 mix / dabang / franchise / specialty / tip (`com.naeilo.widget.support.*`).
- 2026-10-14 사용자 답: **내부 테스트 기간은 무료**. 구독·가격·무료/프리미엄 경계·결제 방식은 차후 결정.
- 후원 단계(인앱 결제)는 차후 전면 재검토.

## 4. 기능 목록 (실제 구현 기준)

### 웹 (naeilo.com, `web/`)
| 탭/영역 | 기능 |
|---|---|
| 탭 | 홈 · 종목 · 분석 · 설정 (앱과 같은 이름·순서, 미션은 앱 전용). 2026-10-15 개편, 계획 `docs/plans/web-tabs.md` |
| 홈 (dash) | 목표 KPI, 도달 예상, 목표 진행(공유 이미지), 본전까지 카드(6개월·1년·3년 확률), 다가오는 일정(가까운 3개), 새 소식 |
| 종목 | 보유 종목 편집(정렬·✎ 고치기), 종목 찾기(한·영·티커·코드), 국내 ETF 대용 추정, 국내 주식 합계(숨김 옵션), 종목별 가격·포트폴리오 진단(규칙 기반), 기간 수익률, 거래 기록 |
| 분석 (analysis) | 목록(허브)에서 하나 골라 그 화면만: 내 길(지난 3년·미래 그래프, 내 기록, 비중 조정안 비교, 자세히 안에 적중 기록판·1000칸) → 목표일 전망(몬테카를로, 렌즈·슬라이더·만약에, 자세히 안에 계산 옵션·모형 값·연구용 비교) → 금리 충격 테스트 → 외부 요인 → 환율 영향 → 배당·세금 |
| 설정 | 내 목표(맨 위), 알림(웹 푸시), 화면, 표시 옵션, 현금, 기기 동기화·다른 기기로 옮기기·JSON, 모형 설정, 개발자용(GitHub 연결·시세 수집, 개발자 모드에서만) |
| 기타 | 첫 방문 샘플(가상 종목 DRNK 4주 + QQQ 1주)과 세리 말풍선, 공유 이미지(1000칸), Beyora 블로그, 다크 모드, PWA, 안내·개인정보 페이지, 원고·후원자 관리 페이지(`store-admin.html`, 개발자용) |

### iOS 앱 (`ios-app/`, TestFlight 내부 테스트 중)
| 영역 | 기능 |
|---|---|
| 탭 | 홈 · 종목(hold) · 분석 · 미션(board) · 설정 |
| 홈 | 어제 종가 기준 평가액, 본전 진행, 쉼터 상자, 루틴 카드, 미니 경로, 홈 리마인드와 소식함 |
| 첫 질문·루트 | 회복 / 목표 / 시작 전 루트, 목표 기본값(확률 50% 근처) |
| 분석 | 내 길, 목표일 전망(웹과 같은 몬테카를로를 Swift로 이식), 금리 시나리오, 외부 요인, 배당·세금, 환율 영향, 한눈에 보기 |
| 미션 | 미션 판(1000칸), 인터미션(4주·3달, 서버 시각 잠금), 회복 경로·목표 경로, 이번 주 예보, 공유 카드 |
| 오늘의 1분 | 보유 종목 기반 퀴즈 (`AppModel.swift` 안에서 생성) |
| 인물·쉼터 | 인물 5명(세리·시오·선배·이르·수아)과 대사, 쉼터 물건 배치·배경, 인물 자세히 보기("투자하는/소설 속" 두 갈래, 사건 모델 4컷), 내 캐릭터 만들기 |
| 서재 | 이야기(외전, 1권, 한/EN; 영문판 원고 올리기는 보류), 유료 장(워커 `/store/book`) |
| 게임 | 판 깨기(1000칸 벽돌깨기, 12단계, 주간 순위판 `/scores`는 보류), 평정 지수(가위바위보 지수)와 습관 사다리, 평행 세계의 나(세 명 경주, 모의 바구니 1개) |
| 위젯 | 홈: 자산·미래·블록·속도·목표·움직임·미래(대형). 잠금화면: 자산·목표·미래·목표가. 인물 위젯 4종(추이·회복·블록·움직임). 서재 위젯. 금액 가리기, 잠금 해제 조건 |
| 설정 | 시세 기준, 알림(로컬), 동기화, 위젯, 세금, 사용법, 앱 아이콘, 백업 내보내기/가져오기, 후원 |
| 테스트 전용 | 국내 종목 실시간 시세(5종목, Yahoo), 개발자 전체 열기(`devAll`) |
