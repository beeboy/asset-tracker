## 확인 필요·나중에
- 웹 개발자용 `web/app.js` 에도 같은 목표 문구가 있음 (GitHub 연결 금지라 이번엔 안 고침).
- 설정 > 루트 바꾸기(SettingsDetail.swift, A)의 "목표 루트 · 플러스" 설명 문구는 A 몫.
- 목표 미션 판의 월 체크인 할 일("앱에서 이번 달 적립 기록하기" 등, `goalMonthSteps`)은 판·인터미션이 함께 써서 그대로.
- 원문 "중간 크기 … 위젯"은 중간 위젯이 삭제된 뒤라 틀린 말이었음 (새 문구엔 크기 없음). 실제 보상 위젯이 무엇인지 확인 필요.
