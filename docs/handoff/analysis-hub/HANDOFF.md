# 분석 탭 허브 화면 개편 인계

디자인 캔버스: "naeilo 분석 허브 시안" (claude.ai 아티팩트)
같은 폴더의 `Main.dc.html`이 목업 원본이다. 마크업·색·간격·문구는 여기서 가져올 것.
대상 코드: `ios-app/Naeilo/Views/AnalysisView.swift` (허브), 필요하면 `AnalysisDetail.swift`.

## 왜 바꾸나 (사용자 피드백 요약)
- 일반 사용자가 "분석 화면이 어렵다"고 함.
- 상세 화면 7개는 문장형 답("한 달에 평균 약 4만 6천원이 배당으로 들어와요")이라 잘 읽힘. 허브만 숫자 조각을 가져와서 어려움.
  - "이익 3년 -8%", "달러 100%", "연 55만원"은 카드 부제의 질문에 대한 답이 아니다.
  - "가능성 반반이에요"와 "34%"가 나란히 있어 서로 모순돼 보인다.
  - 색이 초록·보라·남색·하늘색으로 섞여 있어 의미가 없다.
  - 7개 카드의 무게가 같아서 어디부터 봐야 할지 모른다.

## 바꾸는 것 (위에서 아래로)
1. **내 투자 습관 = 위젯 영역**: 아이폰 왼쪽 위젯 페이지처럼 성격이 다른 영역이다. 위치는 맨 위 그대로 둔다.
   - 얇은 띠로 바꾼다: 캐릭터, "내 투자 습관", "기록 1/10", "9건 더 모으면 나와 닮은 인물을 알려드려요", 진행 막대.
   - 시오 대사는 허브에서 빼고 상세 화면에만 둔다.
   - 띠 아래 구분선을 둬서 "여기부터 분석"을 나눈다.
2. **새 카드 "지금 내 상황"(결론 요약)**: 초록 배경 카드.
   - 첫 문장 "목표까지 절반 왔어요. 지금대로면 3번 중 1번은 목표일에 10억에 닿아요."
   - 그 아래 진행 막대: 지금 5.01억 / 2029.10 · 목표 10억.
   - 마지막 한 줄: "자산의 67%가 테슬라라서 …"처럼 가장 큰 위험을 말한다. 이 문장은 데이터로 만든다(최대 비중 종목과 비중).
3. **나머지 카드 7개를 그룹 제목 3개로 묶는다**
   - 목표에 닿을까?: 내 길 · 목표일 전망 · 금리 충격 테스트
   - 지금 내 돈은 얼마나 흔들릴까?: 외부 요인 · 환율 영향 · 종목 한눈에
   - 들어오고 나갈 돈: 배당·세금
   - 배당·세금이 맨 뒤로 가므로 상세 스와이프 순서도 같이 바꾼다(점 8개 순서 = 허브 순서).
4. **카드 하나의 형태**: 작은 회색 줄 "제목 · 질문" → 굵은 답 문장 → 회색 보조 한 줄 → 오른쪽 `>`.
   - 답 문장은 **해당 상세 화면 첫 문장을 줄인 것**이다. 허브 전용 숫자를 따로 계산하지 않는다(파일 88행 주석 원칙 유지).
   - 카드별 문구는 목업 그대로. 예: 금리 충격 "목표가 1년 6개월 늦어져요", 외부 요인 "발표날 보통 ±200만원 움직여요" + D-7 배지.
   - 종목 한눈에는 비중 막대(테슬라 67 / 엔비디아 18 / 나머지 15)를 넣는다.
   - 배당·세금은 두 줄로 쓴다: 들어올 배당(초록) / 낼 양도세(주황). 한 숫자로 합치지 않는다.
   - 환율 영향의 "환율 10원 오르면 약 [+○만원]"은 자리표시다. 평가액 × 10 / 현재 환율로 계산한다.
5. **색은 의미 3개만 쓴다**: 초록 `#2C5A54` = 들어오는 돈·좋아짐, 주황 `#A8521A` = 나가는 돈·늦어짐·주의, 회색 = 정보. 보라·남색·하늘색은 허브에서 뺀다.
6. **삭제**: 하단 문구 "계산 옵션과 상세 표는 PC naeilo.com에서 크게 봐요."

## 같이 고칠 것
- **외부 요인 상세에 상단 페이지 점이 빠져 있다.** 다른 7개 화면처럼 넣는다.
- **확률 정의를 하나로 맞춘다**: "목표일에 10억 이상일 확률"(현재 34%)만 쓰고 허브에서는 "3번 중 1번"처럼 빈도로 말한다. "반반이에요" 문구는 이 값과 맞지 않으므로 내 길 상세의 제목도 같이 점검한다.
- **페이지끼리 숫자가 부딪히는지 확인한다** (고칠지는 확인 후 사용자와 결정):
  - 내 길 "보통 2029년 8월에 닿음"인데 목표일 확률 34%. 두 값이 같은 시나리오인지 확인한다.
  - 내 길(2029.8에 10억)과 목표일 전망(2029.10에 보통 6.95억)이 같은 가정인지 확인한다.
  - 금리 충격(금리 오르면 목표 가능성 하락)과 외부 요인("미국 금리: 뚜렷한 관계 없음")은 기간이 다르다(장기 vs 하루하루). 외부 요인 쪽에 "단기 흔들림" 기준임을 밝힌다.

## 확인 방법
- iOS 빌드: `cd ios-app && xcodegen && xcodebuild -project NaeiloApp.xcodeproj -target NaeiloApp -sdk iphonesimulator CODE_SIGNING_ALLOWED=NO build`
- 허브 각 카드의 답 숫자가 탭해서 들어간 상세 화면 첫 숫자와 같은지 눈으로 확인.
- 계산 함수 이름을 바꿨다면 `tools/calc_parity.mjs`의 꺼내는 곳도 고친다.
