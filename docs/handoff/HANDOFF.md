# 분석 탭 "내 길" 화면 개편 — B안 + B-2안 인계

디자인 캔버스: "내 길 화면 개선안" (claude.ai 아티팩트, B · 행동 유도형 / B-2 · 구성 바꿔 비교)
같은 폴더의 `B.dc.html`, `Compare.dc.html`이 목업 원본이다. 마크업·색·간격은 여기서 가져올 것.

## 왜 바꾸나 (사용자 피드백 요약)
- "뒤처짐 3.3%"와 "시작 대비 -2.8%"처럼 비슷한 숫자가 달라 혼란.
- "내 길보다 -1,775만원"이 목표(10억)와의 차이로 오해됨. 실제 의미는 '오늘 계획 금액(5.34억) 대비'.
- 주황 "뒤처짐" 옆 초록 "달성 확률 50%" → 좋은지 나쁜지 판단 불가.
- "내 길 / 예보 / 전망 절반" 등 앱 고유 용어가 설명 없이 노출.
- 그래프: Y축 값 없음, 목표선 없음, 오늘 표시 없음, 화면(기간)마다 세로 눈금이 달라 계획선 모양이 바뀌어 보임.
- 다음 행동 안내가 없음. 이 앱의 목적은 "주식 포트폴리오 구성에 따라 목표에 언제 닿는가"이므로, 행동 안내는 저축·목표일 조정이 아니라 **포트폴리오 구성 비교**여야 함.

## B안 — 목표 화면 (B.dc.html)
위에서 아래로:
1. **판정 카드(어두운 배경)**: 목표·목표일·남은 기간 → 제목 "목표까지 가능성은 반반이에요" → 현재/목표 진행 막대(5.16억 / 10억) → "지금 포트폴리오 그대로라면 10억에 닿는 시점은 보통 [예상 시점]이에요. 구성을 바꾸면 이 시점이 달라져요."
2. **"구성에 따라 언제 닿을까?"**: 지금 구성 / 성장 중심 / 안정 중심 3줄을 같은 연도 축(2028~2034)에 표시. 줄마다 점 = 보통(중앙값) 도달 시점, 막대 = 10번 중 8번(10~90 백분위) 범위. 목표일은 세로 점선.
   - 아래 문구: 빨리 닿을 수 있는 구성은 범위도 넓다는 설명.
   - CTA "내 구성 바꿔서 비교해 보기" → B-2로 이동.
3. **"앞으로 3년" 그래프**: 기간 토글(목표일까지 / 지금까지), 10억 목표선 항상 표시, 계획선(보라 점선) + 보통 범위 띠. 세로 눈금은 기간을 바꿔도 고정.
4. "숫자 자세히 보기" 링크 — 기존 세부 숫자(시작 대비 %, 필요 연수익률 등)는 여기로 이동.

## B-2안 — 종목 비중 바꿔 비교 (Compare.dc.html, 동작하는 목업)
1. 제목 "종목 비중을 바꾸면 10억에 닿는 시점이 달라져요" + 목표/목표일.
2. **내 종목 비중**: 전체 구성 색 막대 + 종목별 행(이름, 성격, 처음 대비 변화 "+10%p/그대로", −/+ 5% 버튼, 현재 %). "처음으로" 되돌리기, "+ 종목 추가".
   - 합계 100%면 초록 "합계 100%", 아니면 주황 경고 + 저장 비활성. (경고 상태에서도 시점은 비율 정규화로 계산)
3. **10억에 닿는 시점**: "지금 비중"(회색) vs "바꾼 비중"(초록) 두 줄, 점+막대, 목표일 점선. 비중 변경 시 애니메이션.
4. **해석 카드**: 점이 목표일 앞이면 "보통 목표일 안에 닿아요", 아니면 지금보다 빨라졌는지/늦어졌는지 문장. 막대 폭에 따라 "결과 차이가 커요 / 보통 / 고르게 모여 있어요".
5. "이 비중으로 계획 저장" 버튼 + "과거 수익률로 만든 예상이에요" 안내.

## 목업에서 실제 구현으로 바꿔야 할 것
- 목업의 점·막대 위치는 **예시 공식**(종목 성격별 공격성 점수 → 위치)이다. 실제로는 앱의 시뮬레이션(몬테카를로 등)에서 비중별 10억 도달 시점 분포의 중앙값과 10/90 백분위를 받아 그린다.
- `[종목 A]`, `[ETF B]`, `[현재 비중]`, `[예상 시점]`, `[빠른 시점] ~ [늦은 시점]` 같은 대괄호는 전부 실제 데이터 자리.
- 용어: 내 길 → 계획선, 예보/전망 절반 → 보통 범위(10번 중 N번). "내 길"이라는 이름을 유지할지는 사용자 결정 대기.
- 데이터가 쌓이기 전 "달마다 내 길과 차이" 카드는 숨김.
