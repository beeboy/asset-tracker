# 아침 인사이트 알림 (기획)

2026-10-16 Drinker와 논의한 내용. 구현 전 기획.

## 바라는 느낌
- 뉴스·증시 요약 알림은 이미 넘친다. naeilo 알림은 또 하나의 요약이 아니라, 기분 좋고 보고 싶은 알림이어야 한다.
- "야, 너두? 그래, 나도." 내가 막연히 궁금해하던 걸 옆 친구가 먼저 짚어 주는 느낌. 친구는 츤데레로 웃으며 "내가 널 좀 알지" 한다.
- 예: 내 자산이 내렸고 테슬라 때문이다. 인도량은 좋은데 왜 내렸지? 친구가 말한다. "테슬라는 원래 그래. 사람들 뜻대로 움직이면 그건 테슬라가 아냐. 나스닥과 거꾸로 가고, 가끔은 엔비디아와도 거꾸로 가. 이유? 이유를 알면 다 부자 되는 거지."
- 정답이나 뉴스가 아니라 그 종목·시장의 성격을 알려 준다.

## 정한 것
- **때**: 하루 한 번, 한국장 시작 전 아침 9시 전 정해진 시간. 오르든 내리든 매일 온다. 밤사이 끝난 미국장 이야기가 중심.
- **누가**: 사용자가 홈으로 고른 앱 인물. 말투는 각 인물 성격대로.
- **인사말**: 앱에 저장된 인물별 대사.
- **본문**: 앱 주인(개발자)이 쓴 분석 글. 웹 블로그에 쓴다.
  - 시세를 모아 나눠 주지 않는다는 원칙과 부딪히지 않는다. 주인이 쓴 글을 보내는 것이고, 시세 원본 숫자를 옮겨 싣지 않는다.
  - "종목 + 금액 + 시점" 조언은 쓰지 않는다.
- **거르기**: 서버는 모든 사용자에게 같은 묶음(예: 테슬라·애플·아마존·금리·나스닥)을 보낸다. 폰이 알림을 띄우기 직전에 보유 종목에 맞는 이야기와 금리·나스닥 같은 공통 이야기만 남긴다. 보유 종목은 폰 밖으로 나가지 않는다 (iOS 알림 내용 고쳐 쓰기 확장).
- **말투 바꾸기**: 본문은 원래 그대로. 애플 인텔리전스가 되는 기기(iOS 26+)에서만 본문도 인물 말투로 바꾼다. 알림 직전 확장은 시간·메모리가 작아 미리 해 두는 쪽이 될 수 있다.
- **숫자**: 개별 종목 숫자는 되도록 안 보인다. 내 자산 전체 변화(예: "어제보다 +1.2%")는 폰이 본인 키 시세로 계산해 넣는다.
- **별일 없는 날**: "뭘 기대했어. 별일 없는 게 낫지, 별 볼일 없는 게 나아?" 같은 한마디.
- **받는 사람**: 앱을 깐 사람은 모두 받는다. 오픈 API를 연결하지 않아 계산할 수 없으면 숫자 없이 보낸다 (기본값, 확인 필요).

## 남은 것
- 주인의 분석 글을 Claude로 쓰는 방법: 새 스레드에서 이어 간다.
