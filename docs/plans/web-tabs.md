# 웹 탭 구조 개편 계획 (웹 쉬운 화면 1단계)

> 2026-10-15 결정. 코드 변경 전 계획. 이 문서대로 새 스레드에서 PR 하나로 옮긴다.

## 왜
- 일반 사용자가 웹이 어렵다고 함. 앱은 쉬운 말 개편을 거쳤고 웹은 그 전 구조.
- 첫 화면(내 길)에 카드 7개가 경쟁, 차트 하나에 버튼 17개.
- 같은 개념(관점·렌즈·시나리오·추세 신뢰)이 이름 4개로 나옴.
- 개발자·연구용 기능(시세 수집, 경로 수, 칼만·EMA, 수식)이 일반 화면에 보임.
- 탭이 기능 기준으로 나뉨: 배당·세금은 종목, 환율은 전망, 일정은 기록 탭에 있음.

## 원칙
- 탭 하나 = 사용자 질문 하나. 이름·순서는 앱과 같게 (미션은 앱 전용이라 웹엔 없음).
  - 홈: 나 지금 어디쯤? 언제 도착?
  - 종목: 내가 뭘 가졌지?
  - 분석: 왜 그렇고, 바꾸면 어떻게 돼?
  - 설정: 내 목표와 환경
- 탭 5개(내 길·전망·종목·기록·설정) → 4개(홈·종목·분석·설정). 기록 탭은 없앰.
- 분석 탭은 긴 스크롤이 아니라 목록(허브). 항목마다 한 줄 요약, 누르면 그 화면 하나만.

## 이번 단계에서 안 하는 것
- 홈은 본전 카드와 목표 카드를 둘 다 둔다. 첫 질문(회복/목표 루트)과 "루트에 맞는 카드 하나"는 2단계(홈·내 길 화면)에서.
- 각 화면 안의 버튼·문구 줄이기는 다음 단계들에서 (2 홈·내 길, 3 전망, 4 종목, 5 배당·세금·환율).
- 계산식은 바꾸지 않는다. 섹션을 옮기기만 한다.
