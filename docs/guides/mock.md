# 모의투자 (개발자 투자 모드)

## 구조
- 장부: rule = [모의], real = [실전], ai(꺼 둠).
- 장부를 바꾸는 곳은 `MockDesk` 하나다.
- 기록 `journal.jsonl`(덧붙이기만), 상태 `state.json`.
- 탭: 홈·관찰·선정·일지·계좌. 끄면 미션이 돌아온다.
- 전환은 탭 머리 아이콘. 켤 때 기본 [모의].
- 실전 규칙 목록은 `MockLive.rules` 한 곳이다.

## 하루 구간 (`MockClock`)
- 장 전 → 지켜보기 9:00~9:15 → 고르고 주문 9:15~15:00 → 정리 15:00~15:30 → 마감 후.
- 자동 매수는 고르고 주문 구간만. 팔기·손절은 계속.
- 훑기는 첫 바퀴·60분마다 전체, 사이엔 가까운 종목만.
- 거래대금 10억 이상, 15분 뒤 다시 걸린 종목만 고른다.

## 단타 규칙
- 하루 안에 끝낸다. 15:00에 남은 몫을 다 판다.
- 산 뒤 60분 ±1% 안이면 판다.
- 산 이유가 풀리면 판다.
- 34%씩 나눠 산다. 익절은 반, 남은 몫은 고점 −2%.
- 시장 ETF가 −1% 넘게 내리면 안 산다.
- 조건이 부딪치면 함부로 안 파는 쪽이다. 사는 쪽은 하나라도 막으면 안 산다.
- 놓친 정리는 다음 날 손절을 기다리고 15:00에 판다.
- 규칙 전에 산 종목은 손절·익절로만 판다.
- 미끄러짐 한도 0.5%. 남은 몫은 30분 지정가 뒤 취소.

## 실전 안전장치
- 실전 스위치 기본 끔. 키체인 키 없으면 안 켜진다.
- 하루 손실 −3%(기준 = 토스 평가액 − dailyProfitLoss), 한 번 매수 300만원, 모두 멈춤.
- 계좌를 못 읽으면 실전 매수 안 한다.
- 결제 T+2, 미수 안 씀, 토스 초당 5번.
- 팔기는 앱이 산 몫만. 외부 보유는 보기만.
