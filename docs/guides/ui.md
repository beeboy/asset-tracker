# 화면 규칙

## 꼭 지킬 것
- "종목+금액+시점" 조언 금지. 비율·확률만.
- 사용자에게 토큰·설정을 묻지 않는다. 입력은 수량만. 본인 키는 스스로 켜는 예외다.
- 앱 화면엔 '토스'를 쓰지 않는다. '오픈 API'라 부른다.
- 화면 글은 세게 줄인다. 캐릭터 말투·대사는 그대로(스킬 naeilo-copy-trim).
- 유명인 실명을 쓰지 않는다.

## 탭
- 홈: 평가액 박스 하나가 중심. 모양은 고른다(지평선 기본).
- 종목: 내 돈 기준. 한눈에는 비중 지도, 색 = 기간 등락(빨강 오름).
- 흐름: 큰 흐름 박스 + 차트.
- 분석: 내 길 메인(확률 박스 → 왜 낮을까 → 언제 흔들릴까 → 어떻게 올릴까).
- 목표 확률은 '목표일에 목표 이상' 하나. 허브는 빈도("3번 중 1번").

## 테마
- 상단 박스 테마 일곱. 홈·종목·흐름·분석이 같이 따른다.
- 라이트·다크는 색만 한 쌍. 밝기 모드는 설정 > 화면.

## 위젯
- 이름표는 `Catalog`, 잠금은 `Gate` 하나.
- 잠금화면은 흰색 명암만. 금액은 잠긴 동안 가린다.
- 워치 위젯 값은 아이폰이 보낸다. 워치는 그리기만.
- 안드로이드 잠금화면 위젯은 보류다.

## 구독
- 7일 무료 → 월 1,000원·연 9,000원.
- 7일 뒤 안 하면 위젯 전부와 목표·확률 전망만 잠근다.
- 첫 출시는 대한민국만. 미국은 영어판 뒤.
