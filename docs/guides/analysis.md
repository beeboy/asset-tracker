# 분석 화면 계산 규칙

## 목표일 전망
- 신중하게 = 추세 0%, 지난 3년처럼 = 100%. 버튼·슬라이더는 한 축.
- 차트는 선형 축.
- 도달 시점은 첫 도달 10·50·90%.
- 위젯은 앱 화면을 따른다. 회복 루트 페이스 목표일 = 시작 + 1년, 전망은 3년.

## 금리 충격 테스트
- 목표일 전망이 기준선. 변화량만 보인다.
- 프리셋 −0.5 / 0 / 작년 실제 / +2.5.
- 이동 식 = 3년 b 합 ÷ 3 × β.
- 금리 결정 전날 알림은 6주 반복 규칙으로 90일만. 근사일이라 적는다.
- 금리→이익 분석은 Shiller 데이터(S&P는 재배포 제한).

## 외부 요인
- 순위 단위는 '보통 한 달'(21거래일 변화 표준편차, factors.sd).
- 순위 = factors.sd × 민감도 합계 절댓값. 요인끼리 더하지 않는다.
- 합계 < 평가액 0.1% 또는 같은 방향 50%±5%p면 "뚜렷한 관계 없음".
- 판정: 0.1% 미만 거의 그대로, 2% 미만 조금, 이상 많이. 경고는 factors.max 초과.
- 신뢰도 "10번 중 N번" = 같은 방향 비율.
- 일정 금액은 `EXT_EVENTS.sd` 가정값. '가정값'이라 적고 나쁜 쪽(−sd)으로 연다.
- 과거 재생은 고정 표(웹 REPLAYS = 앱 SiteCalc.replays). 이력 없는 종목은 시장 β 1.
- 회고·다음 날 9시 알림은 앱만, 기기 저장.
- 관계 약한 종목은 3개 넘으면 묶는다.

## 환율 영향
- "지금 환율"은 valFx 하나. 차트·띠는 지금 환율.

## 배당·세금
- "알아두면 좋은 것"은 사실 말투. 시점 조언 금지. "매매 권유가 아니에요"는 둔다.

## 미션·습관
- 목표 칸은 회복 루트까지 100칸. 공유·벽돌깨기는 1000칸.
- 다음 미션 하나만 크게. 페이스는 목표일 ±1개월(goalPace).
- 주간 예보 범위는 그 주 처음 연 날 값을 기기에 고정(remind.v1). 백업·동기화 안 함.
- 맞혀보기 배지 1·3·5·10·20번.
- 평정 지수 화면 이름은 "내 투자 습관".

## 평행 세계
- 차이 1.0%p 미만이면 "비슷해요", 1등 칩 숨김.
- 유리/불리 배지는 규칙·그냥 둠 끝값 비교.
